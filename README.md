Proof Protocol specifications are published under two Creative Commons licenses, split deliberately by document type. This is a policy, not an inconsistency. Read below before assuming a mismatched license on any given spec is an error.
 
## PP-SPEC-001 through PP-SPEC-017 — CC BY 4.0
 
These are architecture and interface specifications: protocol formats, API definitions, scoring formulas, anchoring mechanisms. They are licensed CC BY 4.0, attribution required, adaptation and implementation permitted. This is intentional. Interoperability requires implementers to translate, extend, and adapt these specs into different languages, frameworks, and domains without asking permission each time. Broad adoption of the architecture is the goal for this tier, not restriction.
 
CC BY 4.0 grants are irrevocable. These seventeen specifications remain CC BY 4.0 permanently, regardless of any future change to this policy.
 
## PP-SPEC-018 onward — CC BY-ND 4.0
 
Beginning with PP-SPEC-018, doctrine and positioning specifications, definitions, structural claims, and named concepts that make an originating claim rather than defining an interface, are licensed CC BY-ND 4.0. Attribution is required. Derivative works, adaptations, and reworded restatements are not permitted without direct permission.
 
This tier exists to prevent a specific failure mode: a concept can be cited correctly, verbatim, with attribution, and cited that way freely. What ND prevents is a third party paraphrasing the same definition into their own formulation and presenting it as independently arrived at, stripping the originating claim while keeping the substance. Architecture specs don't need this protection, nobody is trying to claim credit for an API shape. Doctrine specs do.
 
## Which license applies to a given spec
 
Check the individual repo's own LICENSE file. Every Proof Protocol spec repo states its license explicitly. When in doubt, the rule of thumb is: if the document defines how something is built or implemented, it is very likely CC BY 4.0. If the document defines what something means or why a structure is required, it is very likely CC BY-ND 4.0, effective PP-SPEC-018 forward.
 
## Requesting derivative use of an ND-licensed spec
 
CC BY-ND 4.0 does not block quotation, citation, or verbatim reproduction with attribution. It blocks only adaptation. If you want to incorporate a PP-SPEC-018-or-later concept into your own framework in your own words rather than quoting it directly, contact the author for a one-off written permission. Terms are granted on a case-by-case basis and typically require attribution back to the originating specification.
